# apps

Petites applications web personnelles, servies par GitHub Pages depuis la branche `main`.

Chaque application vit dans son propre dossier à la racine, avec un `index.html` autonome.
Les données de chaque app restent dans le navigateur de l'appareil (IndexedDB).

| App | Dossier | Adresse |
| --- | --- | --- |
| Suivi Muscu 5 jours | `suivi-muscu/` | https://paname75.github.io/apps/suivi-muscu/ |

## Ajouter une app

1. Créer un dossier `nom-de-l-app/` avec `index.html`, `apple-touch-icon.png` (180 × 180) et `manifest.webmanifest`.
2. Ajouter une entrée dans `index.html` à la racine et une ligne dans ce tableau.

## Installer sur iPhone

Ouvrir l'adresse de l'app dans Safari, puis Partager → Sur l'écran d'accueil.
